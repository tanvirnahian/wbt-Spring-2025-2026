
FITZONE GYM MANAGEMENT SYSTEM

HOW TO RUN:

1. Install XAMPP or any PHP server.
2. Copy the project folder into htdocs.
3. Start Apache from XAMPP.
4. Open browser and visit:
   http://localhost/gym_management_system

FEATURES:
- Modern UI Design
- Member Registration
- Member List Display
- Responsive Layout
- Pure HTML, CSS & PHP
